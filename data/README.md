# 愛知県 国勢調査（令和2年＝2020年）小地域境界データ GeoJSON

チラシ配布マップWebアプリ用。町丁・字等の境界ポリゴンに世帯数（SETAI）・人口（JINKO）が付いたデータ。

## 出典・ライセンス表記

**出典：政府統計の総合窓口(e-Stat)（https://www.e-stat.go.jp/）を加工して作成**

- 政府統計名：国勢調査 ／ 調査年：2020年（令和2年）
- 集計単位：小地域（町丁・字等）（JGD2011）
- 測地系・形式：世界測地系緯度経度（JGD2011 地理座標）・Shapefile
- 対象：愛知県（都道府県コード 23）
- 取得日：2026-09-07
- 取得URL：
  `https://www.e-stat.go.jp/gis/statmap-search/data?dlserveyId=A002005212020&code=23&coordSys=1&format=shape&downloadType=5&datum=2011`
  （検索ページ：https://www.e-stat.go.jp/gis/statmap-search?type=2 ）
- 取得ファイル名：`A002005212020DDSWC23-JGD2011.zip`（9,215,778 bytes）
  → 展開後 `r2ka23.shp / .shx / .dbf(Shift_JIS) / .prj`（`raw/` に保管）
- 元データ .prj：`GEOGCS["GCS_JGD_2011", ...]`（EPSG:6668）。JGD2011の緯度経度はWGS84(EPSG:4326)と実用上同一のため、GeoJSONは CRS84（経度,緯度）として扱う。

## 変換仕様

- ジオメトリ：全件 `Polygon`（穴付き75件）。**簡略化（頂点間引き）は行っていない**
- 座標：小数6桁に丸め（約0.1m精度）。Feature の `id` に KEY_CODE を設定
- 属性：元dbf 29フィールドのうち下記14フィールドのみ保持（PERIMETER, KIHON1, KBSUM 等は除外）

## フィールド定義（properties）

| フィールド | 型 | 内容 |
|---|---|---|
| KEY_CODE | 文字列(11桁) | 小地域の一意キー ＝ PREF+CITY+S_AREA |
| PREF | 文字列(2桁) | 都道府県コード（愛知県=23） |
| CITY | 文字列(3桁) | 市区町村コード（例：蟹江町=425、名古屋市千種区=101）。全国地方公共団体コードの5桁はPREF+CITY |
| S_AREA | 文字列(6桁) | 町丁・字等コード |
| PREF_NAME | 文字列 | 都道府県名 |
| CITY_NAME | 文字列 | 市区町村名（政令市は「名古屋市千種区」のように区まで） |
| S_NAME | 文字列 | 町丁・字等名（例：本町一丁目、大字須成）。空文字のこともある（水面など） |
| HCODE | 整数 | 行政区域コード。**8101＝町丁・字等、8154＝水面調査区**（下記注意） |
| AREA | 実数 | 面積（㎡）※元データ値 |
| KIGO_E | 文字列 | 分割記号。同一の町丁・字等が複数ポリゴンに分かれる場合 E1, E2, E3… が付く（下記注意）。単一ポリゴンなら空文字 |
| JINKO | 整数 | 人口（令和2年国勢調査） |
| SETAI | 整数 | 世帯数（令和2年国勢調査）※チラシ配布の主指標 |
| X_CODE | 実数 | 代表点 経度（度） |
| Y_CODE | 実数 | 代表点 緯度（度） |

## 利用上の注意（重要）

### 1. KIGO_E が E2 以降のポリゴンは SETAI=0・JINKO=0
同じ町丁・字等が飛び地などで複数ポリゴンに分かれる場合、人口・世帯数は **E1 のポリゴンにのみ全量が入り、E2 以降は 0** になっている（KIGO_E が空なら単一ポリゴンで値あり）。
本データでの実測：E1=370件（SETAI合計195,118）、E2=370件・E3=86件・E4以降=94件はすべてSETAI=0。
→ 世帯数を集計する分には E2以降を足しても二重計上にはならない（0なので）。ただし **地図上で「この区画は0世帯」と表示すると誤解を招く**。E2以降の区画は E1 と同じ KEY_CODE を持つので、表示時は同一 KEY_CODE の合計値を全ポリゴンに配る、または「E1に計上」と注記するのが望ましい。
例：蟹江町「大字須成」は E1〜E4 の4ポリゴンに分かれ、SETAI 1,297 はE1のみ。

### 2. HCODE=8154 は水面調査区
河川・港湾などの水面。愛知県内に34件。S_NAME が空のものも多い。SETAI はほぼ0（1件のみSETAI=1）。配布対象外として除外またはグレー表示を推奨。

### 3. 参考：全県合計値
SETAI合計 3,238,301 世帯／JINKO合計 7,542,415 人（令和2年国勢調査 愛知県の確定値と一致）。

### 4. 世帯数は2020年10月1日時点
新築分譲地・タワーマンション等は現況と乖離することがある。
